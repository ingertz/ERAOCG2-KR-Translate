☆基本設計方針
特に有用な効果を持たない＋展開で使用されないと思われる旧ジュラックのみなさんは可能な限り実装しない。（魔改造してまで採用するほど新ジュラックが弱くないし、インクの染みみたいな効果はあっても使われないので）
新ジュラックは再現可能な範囲で効果そのまま実装（基本的に鱗獣縛りが付くので、事故率を上げずに悪用はできない……はず。）

先攻展開は《ジュラック・アステロ》などで薄く受けて、超えてきた相手に《ジュラック・メテオ》を投げて更地にしてから次ターンで既存鱗獣とコンボでワンショット。
後攻展開はいろいろ頑張る。（無理）

☆実装したもの
①ジュラック側の必須要素
《ジュラック・スティゴ》：初動兼過労死枠、SS制限も基本設計に沿っている。効果の完全再現が技術力の問題で難しかったのでやや強化になってしまった。（レベルと同値になるようSS→合計レベル以下＋可能な限りSS）
《ジュラック・メガロ》：スティゴから持ってきて余裕があれば割って墓地にアステロ送ったり、そうでなければ連続シンクロに繋げる枠。
《ジュラック・アウロ》：スティゴから持ってきてスティゴを連続蘇生させて連続シンクロに繋げる枠。上と合わせて2種はどちらも居ないと基本設計が崩壊する。
《ジュラック・アステロ》：無いと話が始まらない。
《ジュラック・メテオ》：同上。
《ジュラック・ヴェルヒプト》：基本展開で必要。効果は弱いが基本的には経由でしか使わないのでほぼそのままで。効果実装のためシンクロ召喚処理にダークガイア用の処理を移植した(1028本体のものに書き加えている)
《ジュラック・ヴォルケーノ》：まあまあ重要度が高い。必須かどうかは謎。
②必須ではないが選択肢として（後半は基本設計方針に逆らっている気もしているので諸説）
《ジュラック・インパクト》：効果自体弱いわけではないとは思うし唯一のテーマ罠なのだが、本当に使うのかと言われると諸説ある。一度限定で除外ジュラック回収からの再セット位できても良いかも？
《ジュラック・ガリム》：スティゴ効果で墓地へ送るカードの幅を考えるとレベルの枠は広げておいた方がいいため。チューナー枠で効果がNPCに対して強力なので《ジュラック・メテオ》の蘇生先として魅力有。
《ジュラック・タイタン》：要るか要らないかで言えばかなり要らない寄りだが、1+9で《ジュラック・アステロ》を作れるのとスティゴ効果で高レベルを墓地へ送る可能性を考慮して。（効果再現度の都合あんまり意味なかったけど）
《ジュラック・プティラ》：スティゴ効果で墓地へ送るカードの幅を考えるとレベルの枠は広げておいた方がいいため。一応上と合わせて《ジュラック・ヴェルヒプト》にはなる。（採用優先度低）
《ジュラック・モノロフ》：スティゴ効果で墓地へ送るカードの幅を考えるとレベルの枠は広げておいた方がいいため。《ジュラック・ギガノト》との兼ね合いで縁故採用だが、その《ジュラック・ギガノト》がそもそも不要説。
《ジュラック・ギガノト》：一応《オーバーテクス・ゴアトルス》絡みで展開中に経由するため用意したが、効果が新ジュラックや鱗獣の除外戦術と噛み合ってないし必然性も感じないので採用を見送った方がいい疑惑もある。
③ジュラックではないが必須要素
《葬角のカルノヴルス》：基本展開過程で必要なのと、単純に効果が現代基準で採用圏内。《ジュラック・メテオ》効果《葬角のカルノヴルス》SSの流れは強力。
④欲しかったので勝手に作った
《ディノインフィニティ》：《ジュラック・メテオ》後の《葬角のカルノヴルス》バトルフェイズ効果とか、後手ゲームで盤面更地にしてから《幻創のミセラサウルス》効果で呼んできてワンショットみたいな。

メインモンスター　　　10種

☆現状のつよいところ
ひたすら全体除去連打。先攻展開は薄くと言いつつも結構硬い盤面にはなる。
きちんと展開が通れば先攻2ターン目にゲームは終わる。

☆現状のよわいところ
全体除去後の後続を用意する力や高打点を得るルートが外部パーツ依存。
《ジュラック・スティゴ》を止められた場合に次善策が無い。（依存度が高過ぎる）
鱗獣ゆえに初動を用意する手段は多いが、それでもなお用意できなかった場合に何もできず、その後の選択肢を増やそうとすると事故率が上がる。
ぶっちゃけ既存鱗獣族に《ジュラック・メガロ》《ジュラック・メテオ》《ジュラック・アステロ》辺りを出張させるほうが強い気がする。

☆もし効果を改造するなら（基本的にテーマ統一力を上げる方針で）
《ジュラック・インパクト》：除外ゾーンのジュラックモンスターを2枚回収して、自身を墓地から再セット。次に発動した時自身を除外。（メテオ/アステロの再利用と維持能力強化）
《ジュラック・ヴェルヒプト》：下振れたときにここで止まることがあるので、不採用になった同系モチーフである《ジュラック・ヴェロー》の被戦闘破壊時下級リクルート効果を移植する。（戦闘破壊に限らずあらゆる破壊対応でもいいかも）
《ジュラック・ギガノト》：強化幅を上昇(200→300に)する。イラストが似ている《ジュラック・モノロフ》の全体攻撃効果を移植する。
《ジュラック・タイタン》：ターン1で墓地からレベル以上になるようジュラックを除外しながら自己蘇生。（使い終わったメテオをコストにする感じで）
《ジュラック・ガリム》：素引きのバリューが現代基準で低すぎるので、手札から自身をデッキに戻して《ジュラック・ヴォルケーノ》をサーチとか。
《ジュラック・プティラ》：同上。このあたりの《ジュラック・スティゴ》でSSする前提のレベル調整用下級は必須でないのに採用すると事故率が上昇するという問題を抱えているため、鱗獣縛りを付けてターン1手札から自己SSとかも有りか？
《ジュラック・モノロフ》：同上。何ならこれはギガノトの素材条件をチューナー不要にしながら（あるいはプティラをチューナー代わりに使えるようにして）ギガノトをシンクロチューナーにすることで1枠減らしたほうがいいまである。

《ジュラック・ヴォルケーノ》：③が複数除去から1枚しか守れていないので発動回数制限を付けない。（実装側の問題の可能性もありけり）特殊召喚元をデッキだけでなく手札・墓地からも可能にする。（構築側の事故率削減と構築枠圧縮目的）

《ジュラック・スティゴ》：変更不要。これ以上強化するのは流石にやりすぎだし、そもそもこのカードへの依存度が高すぎることが問題。
《ジュラック・メガロ》：変更不要。これ以上強化するのは流石にやりすぎだが、強いて言えば②効果の後にNS権を増やしてもいいかも。（引いたところで大半の鱗獣は自己SS出来ず大抵召喚権も使っているので）
《ジュラック・アウロ》：変更不要。素引きは事故要因でしかないが、それでもなお必須枠なので他のバリューとの兼ね合いを考えればやや弱いくらいがちょうど良い。
《ジュラック・アステロ》：変更不要。これ以上強化するのは流石にやりすぎだが、後手ゲームのことを考えるなら自分ターンで③効果を撃てていいかも。
《ジュラック・メテオ》：変更不要。NPCの自爆回避のためにも相手だけ全滅でもいい気はするが、元のデザインを損なっているし流石にそれは強すぎる。
