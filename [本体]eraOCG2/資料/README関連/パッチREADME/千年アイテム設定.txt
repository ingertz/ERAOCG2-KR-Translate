
【千年スマホ】
作成協力：SOLテクノロジー社協力（超AI、IGNIS）
企画者　：鴻上聖
計画　　：イグニス計画準備段階
元々の持主：？？？　→　水遣い
発見場所：不明

マスター・デュエルで得た多大なる理不尽な決闘データで作られたAIがインストールされてるスマートフォン。
どんなことを聞いたり、欲しい機能を願えばその通りのモノが作られる……時がある…
ゾークの干渉で世界の真実（ヌメロンコード）に到達する……も、期待されていたよりは出力が遅く、現実のAIの進化に追いつかれそうである。
原因としては、ランダムな情報の羅列であるヌメロンコードからAIが直接情報を引っ張っているので恐ろしく時間がかかる。
KCで治してもらった後、ソシャゲや漫画にハマった水遣いが肌身離さず持つようになった。

計画としてはイグニス計画の元となる基本的な技術だけを詰め込んだAIの性能テスト、改善ををKCから貰った資金の許す限り行った。
結果スマホサイズの端末に入れられるAIが完成して、計画はさらに進もうとしたところ、KCに計画がバレ、倫理を理由に凍結された。


【千年ドア】
作成協力：ハートランド研究所
企画者　：Dr.フェイカー
計画　　：スフィア・フィールド砲計画
所有者　：ラビュリンス姫
発見場所：魔界、オークション

アニメにあったスフィア・フィールド砲の次元連結システムのテストベッド。
とりあえず5キロ程度の次元移動は可能となったが企画の締め切りのために提出。
ゾークの干渉で次元同士を連結できるように。
次元移動が得意な水遣いに出力を安定させ、ラビュリンス城の宝物庫に常につながるようにされた。

計画としてはZexal本編のアストラル世界攻撃に、ハルトのバリアンの力を安定、増幅させるための装置のテストベッド
時限連結は成功したものの、アストラル世界にはつながらなかったのと、期限が迫ってきたため適当に投棄。
完成度が高まっているとのこと。

【千年マーカー】
作成協力：I2社
企画者　：ペガサス
計画　　：SOLIDs空中ペン試作企画
所有者　：ヒュプノシスター
発見場所：王国世界、ゴブリンの館

何もない空間にソリッドヴィジョンで絵を描ける、水などでこすると落ちるペン。
ゾークの干渉で魔力を持たない者でも、ルーン文字を書き込めるように
ほかのアイテムと比べてかなり地味ではあるが……その光のインクはディスクの読み込みに干渉できる。
作成途中にて試作インクのコンテナをいくつか紛失してしまったとのこと。

企画費用は払われていたのでそれなりに試作品を作成したが、そもそもの計画が没になったので企画は凍結されたまま倉庫送りに。
それら在庫も海外グールズグループの盗難に合い、ほとんどが裏市場に流れてしまった。
ERAカードの作成には在庫強奪されたこのインクが使われている。


【千年カメラ 】
作成協力：レオ・コーポレーション
企画者　：赤馬零児
計画　　：簡易トークン出力AIカメラ
所有者　：アザレア
発見場所：近未来世界、DDD本社（デスガイドのバスが襲撃された理由）

取ったモノの、オリジナルカードを製造してしまうシステム。
時々起こる決闘者のデッキに存在しないカードが現れる現象の研究のために作られた。
ゾークの干渉で肉体を写真に閉じ込めることができるように。
なおストーリーで見せたカード化は大量の電力を注がれなくては出せないため、普段使いではそこそこ画質のいいカメラ。

まだ社長になりたての赤馬零児が初めて挑戦することとなったプロジェクト。
レオ・コーポレーション社長は完成した際には義理の弟にプレゼントする予定だったらしい。


【千年マイク】
作成協力：KC製独自開発
企画者　：万丈目準
計画　　：万丈目グループ技術部受注
所有者　：アザレア　→　ペンデュラム・ウィッチ
発見場所：機械世界（レイちゃんの世界）、ヴォルトM-05

個人登録されているKC製の電動であるものすべてを自在に動かせるヘッドセット。
ゾークの干渉で増幅で電子機器なら何でも操れるように。後々に判明したところ、実際に干渉しているのは精霊である。
精霊と直接会話することで現実に干渉を起こすことができ、それが機械に現れやすかった。

作成時点で万丈目が兄たちから突然吹っ掛けられ、制作を任され、
カードの精霊を使ってごまかしたという出鱈目みたいな製品。

【千年ディスク】
作成協力：KC製独自開発
発見場所：乙女の里→KC研究所

より精密で美しいソリッドヴィジョンを目指すため制作。
すべての成果物の情報を見れる立場のため、他会社に向けて技術差を見せつけるためという、ちょっと意地悪な目的で制作された。
ゾークの干渉でアラメシアの儀に近い性質を持つようになり、カードの質によって本体を引っ張ってこれるように。
別の世界出身の白き乙女が届けに来たおかげで、唯一回収に成功。そのまま社長の指示のもと量産された。
この際の完成した量産型ミレニアムがプレイヤーの手に渡り、データ収集に使われる。
そのデータで改良型がさらに量産され、4章の襲撃の際に一部ドミノシティ周辺の決闘者とセキュリティの手に。
なお使い心地はかなり好評でほかのデュエルディスクのシェアを大きく掴んだ。

オリジナルの千年ディスクはKC社内部にて厳重に保管されていたが、対ウィッチ戦でついに解放されプレイヤーの手元に。

音mが決闘世界に持ってきた
