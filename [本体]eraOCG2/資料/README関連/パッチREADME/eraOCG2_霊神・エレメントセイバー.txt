〇霊神・エレメントセイバー
属性：複数
種族：戦士族（エレメントセイバー）・複数（霊神）
牝性：有
攻略対象：有
改造度：４
モチーフ：精霊信仰

6つの属性を操る戦士たちのテーマ。下級モンスターの「エレメントセイバー」と最上級モンスターの「霊神」で構成されている。
もともとの特徴としては墓地で属性を変更して手札の特殊召喚モンスターの召喚条件を満たす。という使い方をするのだが、
eraOCG2では墓地のカードに対して属性などを変更する処理が難しいため、「霊神」の召喚条件に限って足りない属性カードを補えるという形で実装している。
「ボチヤミサンタイ」はダムド側の条件判定に手を加えて対応しているが、属性数を参照する召喚条件である場合の例外的な処置であるためダムドの起動効果には対応しない。
