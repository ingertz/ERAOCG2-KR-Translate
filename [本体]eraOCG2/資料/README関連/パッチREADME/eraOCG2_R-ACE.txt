
〇R-ACE（レスキューエース）
属性：炎
種族：戦士族・機械族
牝性：無
攻略対象：無
改造度：２
モチーフ：消防士、消防設備

炎属性のテーマで、消防用パワードスーツを装着した人間の戦士族モンスターと、消防用の設備や乗り物をモチーフにした機械族モンスターが存在する。
EXモンスターが存在せずEXデッキへの制約も少ないため、逆にEXデッキ構築のセンスが問われる。賜炎の咎姫を強く使える炎属性テーマであることに注目したい。
カテゴリ内で最大戦力の巨大消防車"タービュランス"はインパクト抜群。一気に大量の速攻魔法・通常罠カードを伏せる効果のインパクトもとても大きい。
実はレベル１の"ハイドラント"こそが真のテーマの中核であり、如何に消火栓を盤面に維持して的確な妨害やアド稼ぎを上手く出来るかでプレイヤーの技量が試される。
※eraOCG2では効果や召喚条件の都合上、原罪宝スネークアイや、サロス・ナンナを使ったデモンスミス出張などの他テーマとの混合が出来ない点は注意が必要。



---

＜テーマの詳しい解説＞
流石に全盛期は環境tier1級のテーマであっただけのことはあり、基本的なカードの効果はネットに幾らでもあるので割愛。
スネークアイやデモンスミス出張が出来ない、という点を最初に強調したうえで、テーマの動きを改めて確認していこう。

レスキューエースの初動は、本家OCGではエアホイスターからエマージェンシーをサーチして、ハイドラントをリクルートしてタービュランスをサーチ。
墓地のR-ACEカード２枚を除外してタービュランスを出して魔罠を大量に伏せる。アラートを伏せれば、ハイドラントの効果で即時発動してプリベンターをサーチして
さらにアラートを除外してプリベンターを出すことで、ハイドラント＋タービュランス＋プリベンターの３体＋魔罠に伏せ２枚（妨害罠２種類が多い）
ここまでで基本的な展開となる。これでニビルをケアしつつ３妨害になるので、相手の妨害が無ければ順当に戦えるデッキになっている。

この状態から、さらにタービュランス＋プリベンターでリンク２を組んでプリベンター効果で除外したエアホイスターを帰還。
リンク２＋エアホイスターで咎姫を出して、咎姫効果で墓地の炎属性を蘇生してリンク４でアンブロエールやレイジングフェニックスを出せば、
さらに相手ターンに咎姫の墓地効果を絡めて妨害の手数を出せるが、エアホイスター１枚初動だとフィールドのハイドラントが無防備になるため、
実際に狙うならレスキューorアラートを１枚素引きしてるなどで、もう一体モンスターの出力に余力がある状態で狙いたいところ。

また、インパルスには縛りはつくもののハイドラントをデッキから特殊召喚する効果がついているため、手札次第でインパルスも擬似的な初動になれる。
エマージェンシー以外にもヘッドクオーターなど何種類か手札にあればインパルス初動で動けるカードはあるが、実際どこまでなら動けるかは研究次第。

初動モンスターは通常召喚から動くため、初動に誘発を受けた時に貫通する方法に乏しい（恐らくエマージェンシー以外ない）のがテーマの弱点。
使い込んでいくなら、デッキの制限枚数を緩和する依頼をクリアして、エマージェンシーを複数枚デッキに投入できるようにしておきたい。

CPUはフリー誘発効果を使い過ぎてしまうためカードパワーほど脅威ではないのだが、それでもタービュランスの攻守は十分な威圧感がある相手。
