〇ShadDOLL
属性：闇
種族：複数
牝性：有
攻略対象：有
元テーマ：シャドール
モチーフ：人形、リョナ、BDSM、シャドール化（悪堕ち）
専用イベント：無

『MASTER』なる存在に絶対服従する、牝奴隷調教師の役割を与えられた人形たちのテーマ。影糸を変化させた黒いラテックスメイド服を身に纏う。
主に女性の相手プレイヤーをTARGETにしており、デュエルを通した牝奴隷調教に特化しているが、しかしそれは調教と呼ぶには余りにも痛々しい"拷問"である。
テキストの一部が文字化けしているが、これはその世界に生きる人々には認識できないからである。「era」なる電子ゲームのデータが影響しているとか。
相手プレイヤー自身の心の一部を呪縛するフィールド魔法で、ShadDOLL化させた相手プレイヤーの分身を使役し自分自身を調教させるという倒錯プレイが見所。

コンセプト

・相手プレイヤーへの調教（エロ行為）の補助を主目的とした人形たち
　→人形たちに拷問処理を行う牝奴隷調教師としての姿と能力を与え、それに特化したテーマとして再構成を行った（2025/10）
　→従来ERAネフィリムにのみ、相手プレイヤーへの物理ダメージに伴う拷問処理を実行していたが、
　　ミドラーシュ・ウェスターナ（ヒータ意識した独自キャラ）らにも同様の拷問処理を行う処置を追加。ダメージ量で拷問はより苛烈なものにエスカレートしていく。
　　各キャラ4段階まであるが、読んでて気分が悪くなるテキストも多いので、趣味じゃない人は下記のERAウェンディゴ出張、ERAミドラ出張に止めるぐらいが得策。

・「あなた」＝「MASTER」に従う存在として強烈に定義しているため、「あなた」以外のプレイヤー（NPC）には、その効果の多くを使いこなす事はできない。
　※様々なテキストに記載されていないカード処理が組み込まれており、ごく一部の例外を除いて「あなた」を相手にしてもほとんど無害なモンスターとなる。
　そのぶん、相手プレイヤーが調教可能な女の子でない場合も効果が十分に発揮されないようになっており、レート戦や裏通りデュエル系にも使いにくい。

・相手プレイヤーをある程度調教していれば、あらゆるE.R.A系テーマに最小EX1枚（ERAウェンディゴのピン採用）、
　最大でもEX4枚＋ERA融合1枚のERAミドラ出張で十分すぎるぐらいに機能する。
　→屈服刻印Lv1以上でEX起動でERAカード1枚をサーチ可能。さらに相手プレイヤーに調教を施して苦痛刻印を刻み込めば……

・ギミックで縛りはつかないが、フィールド魔法の「ERA影牢の呪縛」に強いデメリットがついている（NPCには使いこなせないようにもなっている）
　ERA的な拷問調教ギミックにおいては「ERA影牢の呪縛」を貼ることが求められるので、ShadDOLLテーマでERA調教をするにはシャドールデッキとして組む必要がある。

・ShadDOLLカードは現状で融合体と魔法カードしか存在していない。メインデッキの融合ギミックとして通常の「シャドール」を使いこなす必要がある。
　→実装して動きが問題なさそうであれば、後々メインデッキの「ShadDOLL」女の子モンスターも追加する感じで拡張したい。
　　（これはターミナルテーマとかも気にせず、よそのテーマの女の子[作者がeraOCG2で獲物にした子]をシャドール化して実装していく想定）

・対戦相手をある程度調教済みで屈服刻印ついてないとギミックは機能しない（なので、組みにくい割にストーリー攻略には使いづらい）
　→シャドールの強化パーツとして使えないこともないが、攻略対象の女の子とのデュエルじゃないとパワーは発揮しきれない。（シャドール自体のギミックが若干レトロ）

簡単な使い方（一般的なERAカードで女の子を調教したりしたいプレイヤーの出張としての利用）
---

条件：相手プレイヤーが屈服刻印Lv1以上、かつ相手があなた（=MASTER）でない場合に使用可能
必要なカード：メインデッキにERA影依融合を１枚
　　　　　　　EXデッキにERAウェンディゴとERAミドラーシュ、ERAミドラの融合素材になるシャドール・ShadDOLLのEXモンスターを入れる。

順序：
EXデッキのERAウェンディゴをEX起動で墓地に送って、
ERA影依融合をサーチ（相手プレイヤーの調教次第ではERAカードを追加でサーチ可能）
手札に加えたERA影依融合を発動。フィールド・墓地に牝がいればEXデッキの
シャドールを素材に出来るので、EXデッキからシャドール２体を墓地に送ってERAミドラーシュを融合召喚する。

結果：
自分フィールドに破壊耐性のついたERAミドラーシュ１体（相手のみ特殊召喚を1ターン1体までに制限する）
ERA影依融合の永続効果で相手をシャドール融合体への攻撃を強制する状態になる。
