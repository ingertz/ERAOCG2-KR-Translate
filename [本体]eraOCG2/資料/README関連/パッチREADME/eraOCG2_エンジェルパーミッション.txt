〇パーシアス
属性：光
種族：天使族
牝性：有
攻略対象：有
改造度：４
モチーフ：天使、パーミッション、ライト月子

光属性・天使族のテーマ。EXデッキを使ったモンスター展開をテーマ内では行わないうえ、メインデッキの上級モンスターが主力の古風なテーマ。
カードゲーム用語での「パーミッション（許可）」タイプのデッキで、構える妨害はカウンター罠（相当の罠）が中心で質が高いが、１ターン中の妨害数はそれなり。
「勇気の天使ヴィクトリカ」の上級モンスター体をパーシアス互換のエースモンスターに据えており、彼女がしっかり活躍できるようにしている。


---

＜テーマの詳しい解説＞
光属性天使族のモンスターで盤面有利を取りつつ、発動無効系カウンター罠（Ｃ不可通常罠）を継続的に構えて戦うタイプのコントロールデッキ。
ライト月子に持たせるためだけに作られたテーマカードたちである。月子ちゃん可愛い、でもデュエルは悪魔じみてる。
舐めてかかってデュエルを挑んだら生半可なデッキでは勝てねーヤバすぎるキャラだった、という感じの超絶地雷枠にしたくてデザイン。
実際に作り終えて握った感触としては、ペンデュラムを貼るまで行ければ強いが、そこに行けない時に罠で凌ぐのは辛い。他の天使族と組むのもありかも。
月子ちゃんに実際に持たせた感じだと、まれに手札がハマる時は強いが、サーチ先の選択に難あり。まあ罠を構えてくる感触はあるのでCPUとしては及第点。

CPUでも扱いやすくするためにEXモンスターの展開などは基本的に行わない。そのため、遊戯王の初心者にも使いやすくなってる感触は結構ある。
唯一、EXのシンクロ・エクシーズをペンデュラムゾーンにセットする部分はハードルがあるが、単にアド稼ぎ用の永続魔法を貼るイメージで捉えればOK。

宣告者や既存の天使族との差別化も兼ねて「モルガナイト」を取り入れられるようにするため、モンスター効果の手札起動をテーマ内で避けた設計にしている。
サーチ範囲もレベル２のデクレアラーを持ってきにくくしていて、手札のデクレアラーでの妨害を天使族サーチ効果で増やすことは難しくしている。
ただし、そのぶんパーシアス罠を手札から撃つことが可能になるギミックがテーマ内にあり、手札にパーシアス罠を持ってきて妨害するようにしている。

盤面の妨害量はフル展開した宣告者（アルデク）のほうが圧倒的に強いが、パーシアスは外部出張なしの天使族だけで動きがほぼ完結しており、
妨害のパーシアス罠を魔罠と手札に、モンスターゾーンのモンスターはアド稼ぎと戦闘要員と機能を散らしていて、一滴などで妨害数が大きく減らないのが強み。
パーシアス罠の万能無効は名称ターン１がついていて連打が出来なくなってる点と、盤面のモンスター達は自前では耐性を持っていない点、
Pカードや「天空の聖域」扱いの「パーシアスの神域」を除去されると盤面やリソース回復が脆くなる、などの弱点を上手く突ければ崩せると思う。
CPUはマスカン待ちしないので、適当なカード効果で踏んでいけばガチデッキの手数なら踏み越えられるんじゃないかな（たぶん）
